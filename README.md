# ONG Esperança Viva - Single Page Application (SPA)

> Aplicação web reativa e acessível desenvolvida em Vanilla JavaScript para a ONG Esperança Viva, focada em captação e gerenciamento de voluntários.

---

## 🚀 Tecnologias Utilizadas

- **HTML5 Semântico:** Estruturação acessível com atributos ARIA e tags de navegação.
- **CSS3 Moderno:** Design Tokens (variáveis), Flexbox, CSS Grid e animações suaves.
- **Vanilla JavaScript (ES6+):** Arquitetura modular, Hash Router para SPA e manipulação do DOM.
- **Web Storage API:** Persistência de dados locais via `localStorage` com tratamento de exceções em JSON.
- **Validação com RegEx:** Verificação reativa em tempo real para campos de formulário (CPF, E-mail, Telefone).

---

## 🎯 Funcionalidades da Aplicação

1. **Navegação SPA (Single Page Application):** Transição fluida entre as rotas `#inicio`, `#projetos` e `#cadastro` sem recarregamento de página (*no-refresh*).
2. **Formulário de Voluntários Reativo:** Validação dinâmica dos campos com feedbacks visuais de erro e sucesso.
3. **Persistência de Dados Local:** Salvamento automático da lista de voluntários cadastrados no navegador.
4. **Interface Acessível (WCAG 2.1):** Suporte à navegação por teclado, alto contraste de cores e estrutura amigável para leitores de tela.
